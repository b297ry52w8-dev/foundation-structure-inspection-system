# 地基及结构检测管理系统 PC 端静态原型

基于《地基及结构检测管理系统 PC端产品需求文档 PRD V1.2》制作的蓝白色企业后台高保真静态原型。项目不依赖框架、构建工具或真实后端，所有数据和交互均在浏览器端模拟。

## 运行方式

### 直接打开

双击 `login.html`，登录后进入工作台。所有页面通过 URL 哈希路由切换，可直接本地运行。

### 本地静态服务（推荐）

在 `prototype` 目录执行任意静态服务器，例如：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080/login.html`。

## 页面与功能

- 公共：登录、工作台、404、消息通知、角色切换
- 合同管理：合同清单/新增/编辑/详情/审批/终止，收款列表/新增/详情/核销/作废，开票列表/新增/详情/任务选择/作废
- 营销管理：客户列表/新增/编辑/详情，工程列表/新增/编辑/详情，委托任务明细平铺列表/新增/详情/派发/改派/催办/取消/批量导入
- 检测管理：检测任务列表/详情/指派/转派/拒绝/开始检测/数据录入/提交审核/历史版本，样品列表/详情/预览/维护，报告列表/生成/编制/编辑/详情/审核/版本/作废/导出
- 基础数据：业务类型、检测项目、检测规范、设备台账、设备申请/领用/归还、流程配置
- 统计分析：一期预留页面
